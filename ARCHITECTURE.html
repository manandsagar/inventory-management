Factory Inventory Management System

System architecture, tech stack, and data flow overview

Tech Stack

Frontend :3000

  • Vue 3.4.21 (Composition API)
  • Vue Router 4.3.0
  • Axios 1.6.7 (HTTP client)
  • Vite 5.2.0 (dev server / build)

Backend :8001

  • Python ≥ 3.11 (run via uv)
  • FastAPI ≥ 0.110.0
  • Uvicorn ≥ 0.24.0 (ASGI server)
  • Pydantic ≥ 2.5.0 (validation)

No database — data is loaded once at process startup from static JSON files in server/data/ into module-level Python lists/dicts (in-memory only; a restart is required to pick up JSON edits).

Response path mirrors this in reverse: filtered lists are validated against Pydantic response_models, returned as JSON, resolved by axios, assigned into raw Vue ref()s (e.g. allOrders, inventoryItems), and re-rendered via dependent computed() properties.

Filter System

Four global filters apply across most views via a singleton composable (useFilters.js) — module-level refs shared by every component that calls it:

Time Period Warehouse Category Order Status

getCurrentFilters() builds { warehouse, category, status } and adds month only when Time Period ≠ "all". api.js appends each present, non-"all" value to a URLSearchParams query string. On the backend, FastAPI's apply_filters() handles warehouse/category/status and filter_by_month() handles month (including quarter codes like Q1-2025) against the in-memory lists.

Note: Inventory has no time dimension — /api/inventory, /api/demand, and /api/backlog do not accept status or month.
